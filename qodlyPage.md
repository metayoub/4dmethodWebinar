Create a modern and responsive “Shareable Business Card” page using Qodly Pages.

Transform the existing static contact details form into a polished digital business card while using only the information available in the reference image.

Do not add any new contact fields such as LinkedIn, website, biography, social networks, company logo, department, notes or status.

## Data to Display

Use only the following information:

### Personal Information

- Profile photo
- Title
- First name
- Last name
- Group
- Email

### Phone Numbers

- Work phone
- Home phone
- Mobile phone

### Professional Information

- Job title
- Company

### Work Address

- Street
- City
- State
- Zip code
- Country

### Home Address

- Street
- City
- State
- Zip code
- Country

## Main Concept

The page must have two states:

1. Business Card View
2. Edit View

The default state must be the Business Card View.

## Business Card View

Create a centered, modern digital business card.

### Profile Header

Display:

- Profile photo
- Title, first name and last name
- Job title
- Company
- Group

Use a clean professional design with:

- White card background
- Rounded corners
- Subtle border
- Soft shadow
- Modern typography
- Comfortable spacing
- A restrained blue accent color

The profile photo should be displayed prominently on the left side on desktop and above the information on mobile.

### Contact Information Section

Display the following values:

- Email
- Work phone
- Home phone
- Mobile phone

Each item should include:

- A simple icon
- A label
- The value
- A clickable action when supported
- An optional copy button

Hide fields that have no value.

### Professional Information Section

Display:

- Job title
- Company
- Group

Use a compact modern card or information grid.

### Address Section

Create two separate cards:

#### Work Address

Display:

- Street
- City
- State
- Zip code
- Country

#### Home Address

Display:

- Street
- City
- State
- Zip code
- Country

On desktop, place the Work Address and Home Address cards side by side.

On smaller screens, stack them vertically.

Do not use the vertical rotated labels from the original page. Use normal horizontal card titles.

Use modern input components with:

- Labels above each field
- Rounded borders
- Clear focus states
- Consistent input heights
- Comfortable spacing
- Validation feedback

Do not use underline-only inputs.

## Visual Direction

The result should look like a modern digital business card rather than a traditional administrative form.

Use:

- Light gray page background
- White surfaces
- Rounded corners between 12px and 16px
- Subtle borders
- Soft shadows
- Blue accent color
- Neutral secondary text
- Consistent spacing based on 8px
- Smooth hover and focus states

Avoid:

- Table-style layouts
- Creating any CSS classes not used or needed- Create any action functions like edit, delete ….
- Rotated labels
- Adding any button
- Heavy borders
- Dense spacing
- Excessive colors
- Unnecessary decorative elements
- Any information not present in the reference image

The final page must preserve all the information from the original contact form while presenting it as a clean, professional and shareable digital business card.
